# IELTS Topic Vocabulary

A Codex skill for learning IELTS vocabulary through themed English articles, topic packs, and review exercises. Themes range from standard IELTS topics to workplace English, AI, Web3, or a topic chosen by the learner.

## Use

Install the folder as `~/.codex/skills/ielts-topic-vocabulary`, restart Codex, then invoke `$ielts-topic-vocabulary` or ask naturally, for example:

> Create a 100-word IELTS vocabulary article about AI and digital business. Mark 15 focus words and add a Chinese glossary and quiz.

By default, a compact lesson introduces 10–15 focus items. If the learner requests 100, the skill provides 100 numbered entries and distinguishes focus vocabulary from additional exposure or review items.

See [`references/topics.md`](references/topics.md) for the topic map and [`SKILL.md`](SKILL.md) for the full workflow.
